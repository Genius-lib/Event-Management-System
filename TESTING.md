# Event Management System - Test Checklist

Test the program using the menu in `main.py`.

- [ ] Program starts and displays the main menu.
- [ ] Four CSV files are present in the `data` folder.
- [ ] The sample data has 30 records total.
- [ ] Events display in date order.
- [ ] Venue list displays 10 sample venues.
- [ ] Add a new venue.
- [ ] Try a venue capacity of zero; it should be rejected.
- [ ] Create an event using an existing venue.
- [ ] Try an invalid date; it should be rejected.
- [ ] Try event capacity greater than venue capacity; it should be rejected.
- [ ] Search for an event by ID or name.
- [ ] Update an event.
- [ ] Cancel a test event.
- [ ] Register a new attendee.
- [ ] Search for an attendee.
- [ ] Register an attendee for an event.
- [ ] Try registering the same attendee twice for the same event; it should be rejected.
- [ ] Try registering when an event is full; it should be rejected.
- [ ] View attendees registered for an event.
- [ ] Confirm remaining places are calculated.
- [ ] Change a registration payment status to Paid or Unpaid.
- [ ] Cancel a registration.
- [ ] View attendance and payment reports.
- [ ] Exit the program.

Use newly created test records for cancellation tests. Do not cancel the sample events unless you want to change your demonstration data.
